# Algoritmos y Estructuras de Datos

Este es un repositorio personal donde subo las resoluciones y trabajos prácticos de la materia Algoritmos y Estructuras de Datos (UNSa). 

El objetivo del repo no es ser una librería para que otros la descarguen o usen, sino mantener un registro ordenado de las estructuras y algoritmos que fuimos programando desde cero a lo largo de la cursada.

## ¿Qué hay en el código?

Todo el código está hecho en **Java** aplicando Programación Orientada a Objetos, sin usar las colecciones nativas del lenguaje (Collections). El repositorio incluye:

* **TADs Básicos:** Implementaciones manuales de Pilas, Colas y Listas (simples y doblemente enlazadas).
* **Recursividad:** Ejercicios prácticos resueltos de forma recursiva.
* **Grafos:** * Modelado de Grafos Dirigidos y No Dirigidos mediante matrices de adyacencia.
  * **Caminos Mínimos:** Algoritmos de Dijkstra y Floyd-Warshall.
  * **Árboles Cubridores (MST):** Algoritmos de Prim y Kruskal (usando Conjuntos Disjuntos).
* **Otros TADs:** Implementación de objetos matemáticos (Racionales, Complejos) y modelos para TPs específicos (Mochilas, Ranking FIFA, etc.).

## Tecnologías
* Java (JDK)
* Paradigma: POO Estricta
